## 输入与方向

`hostGame` 是实际承载玩法的宿主，`sourceGame` 是所需内容或交互的来源。不使用含义可能反转的 A/B 字母作为内部字段。

请求合同包含：

| 字段 | 含义 |
| --- | --- |
| `hostGame` / `sourceGame` | 宿主与来源名称 |
| `description` | 完整自然语言需求，保留到导出计划 |
| `contentKinds` | 可选内容类型：角色、武器、招式、规则、世界、音频、UI、资源或其他 |
| `hostVersion` / `sourceVersion` | 可选准确版本；缺省为 unknown，不自动推断最新版 |

用户可以描述任意游戏组合，系统不会将名称输入解释为已支持。完整角色、动画和交互要求不会被改成固定 Buff 或枪械模板。

## 当前分析结果

模型提出的计划包含标题、摘要、逐项需求、资源需求、接口需求、问题与限制。每项需求的当前处置是需要研究、需要资源或范围外；处置和理由保留在计划中。模型仅能提交分析数据，合同不提供可执行代码、命令、文件操作或成功声明字段。

本地校验追加原始请求、需求引用、任务依赖图和阶段证据。模型返回的分析不能登记适配器，也不能把待研究接口标记为已验证。统一流程把需求 ID 从已接受的需求分析独立绑定到规格，保留不可表达项和全部五份上游；本地可信生成器写出固定源码与绑定缺口。结构通过不代表语义完整；草稿没有游戏 SDK 或真实宿主绑定。

| 阶段 | 当前能力或状态 |
| --- | --- |
| 需求输入与保留 | 通用合同与完整原文 |
| AI 分析 | 单次结构化模型请求，本地校验后展示 |
| 资源与接口分析 | 记录文字层面的需求和缺口，不扫描或上传游戏文件 |
| 单次分析的任务规划 | 输出静态依赖关系与阻断原因；协作执行走独立运行记录 |
| 通用调度 | 依赖调度、并发、预留预算、取消、超时、结构化产物与来源 |
| 多 Agent 协作 | 五类分析角色实际分工，来源与宿主建议可以并行；输出未核实 |
| 统一转换任务 | 五角色后新增一次规格提案调用、本地 AST 校验与工程草稿，同一任务保存预算与依赖 |
| 中断恢复 | 本机原子快照、单写者保护、显式恢复与完成任务去重 |
| 行为内核生成与编译 | CLI/API 接受明确规格，生成锁定 C# 工程，真实 SDK 隔离编译与序列对照；不含游戏引用 |
| Squirrel 与宿主预检 | 同规格确定性生成；真实原生 VM 内核向量；一次用户手动按键、位移及恢复通过；桌面绑定失败，不登记支持 |
| 适配工程草稿 | 固定九文件，含确定性 C#、通用事件接点、完整原文/分析和未绑定清单；不编译、不安装 |
| 正式 Mod 工程生成 | 缺版本化宿主适配器，`readyToGenerate=false` |
| 真实 Mod 编译与修复 | 未实现、`not_run` |
| 安装与游戏验收 | 未实现、`not_run` |
| 可安装状态 | `readyToInstall=false` |

`coverage` 记录需求结构与未知项，不证明模型完整理解了全部语义。单次分析可导出计划 JSON；统一任务另可下载工程草稿 ZIP，包含真实生成源码，不含可安装 Mod、游戏资源或已构建二进制。

## 本地使用

需要 Node.js 24+。

```sh
npm test
npm run dev
```

打开 `http://127.0.0.1:4173`，选择宿主、来源和内容类型，填写完整需求。模型凭据可从本地 `.env` 读取，也可在当前表单中临时输入。配置后重启服务；根地址和模型名称以 `.env.example` 与工作台设置为准。

单次分析调用一次模型；五角色分析正常五次；默认统一流程再增加一次行为规格提案，正常六次。提案只能输出有界 AST、假设和限制，模型不选择源码、文件或命令。本地工程生成零模型调用。上游产物经过角色合同与引用校验再传递；独立方案审查不等于后续规格的语义验收。

没有自动网络重试或自动收费修复。模型格式错误、截断、凭据回显或合同不符会停止。取消会中止观察并丢弃晚到结果；已发出的云端请求仍可能计费。任务启动前按本地 operation 成本预留预算，预留数不等于实际账单。

协作记录默认位于本机 `.gamebridge/`，可用绝对路径 `GAMEBRIDGE_STATE_PATH` 改为其他本地目录。服务重启只恢复中断状态，不自动重发模型。载入任务后可检查并恢复；重放收费任务须明确选择并有足够总预算。已完成角色保持结果和哈希，不重新付费运行。恢复需提供原任务所绑定 origin/model 的凭据；Key 不写入快照。

没有游戏环境时可以分析、提出受限规格并生成无游戏引用的工程草稿；不能据此宣称游戏可行或安装。待适配器、资源和真实环境经过核验后，正式 Mod 生成和执行器才能开放。此统一流程没有启动游戏、编译器或安装程序的绑定。

## 本地服务与公开页面

| 接口 | 作用 |
| --- | --- |
| `GET /api/config` | 本地运行状态和默认供应商配置，不返回 Key |
| `GET /api/adapters` | 当前适配器注册状态；当前列表为空 |
| `GET /api/agent-roles` | 五类分析 Agent 的本地注册合同；不是游戏支持目录 |
| `POST /api/conversions` | 通用转换需求分析，返回校验后的计划与阶段报告 |
| `GET /api/conversions/:id/download` | 下载当前转换计划 JSON |
| `POST /api/runs` / `GET /api/runs` | 建立并启动有预算的协作任务 / 列出本机记录 |
| `GET /api/runs/:id` / `GET /api/runs/:id/download` | 读取状态和逐角色产物 / 导出运行记录 |
| `GET /api/runs/:id/project` | 仅下载该任务已接受的私有工程草稿；无外部路径/handle入口 |
| `POST /api/runs/:id/cancel` | 取消活动任务并保存状态 |
| `POST /api/runs/:id/resume` | 显式恢复，可增加总预算及允许重放；不会重置已预留调用数 |

本地服务只监听 127.0.0.1，并检查 Host、Origin、JSON 类型及请求上限。公开 GitHub Pages 用于展示界面与说明，不收集 Key，也不请求用户本机服务。页面更新不代表工程生成、Mod 更新或游戏转换已完成。

## 凭据与文件

默认 Key 绑定配置的 API origin。切换域名或端口后必须使用对应凭据；界面清除临时旧 Key，后端阻断默认 Key 跨 origin 复用。Key 不保存到浏览器存储、日志、计划或 Git。成功结果和错误均检查凭据回显。

当前只向模型发送文字需求与合同。游戏文件、资源、存档和用户凭据不进入云端或公开仓库。后续的文件转换、工具执行和游戏加载需要独立适配器与明确边界；不能让模型自行执行命令来补齐缺失能力。
