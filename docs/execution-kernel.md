# 转换执行内核：0.8 Alpha

更新于 2026-11-04（Asia/Shanghai）。本轮补充有界行为规格、独立文件产物、通用工具注册和真实离线 C# 编译。执行入口面向开发者，处理明确提供的规格 JSON；自然语言分析尚未自动生成该规格，游戏适配器仍为零。

## 当前执行链

原始请求与独立需求 ID → 行为规格校验 → 确定性生成锁定工程 → 文件产物 → 实际 SDK 隔离编译 → 隔离运行自有验证程序 → 逐步比较 JavaScript、C# 与明确预期。

生成的是独立行为验证库，没有游戏引用或安装包。事件与整数状态可以执行；宿主输入、空间位移、动画、碰撞和伤害没有实现。报告保持 `realModBuild=not_run`、`game=not_run`、`readyToInstall=false`。

## 开发者入口

需要 Node.js 24+。实际验证环境为 macOS arm64 与项目专用 .NET SDK 8.0.427。编译和运行均要求通过 macOS OS 沙盒探针；其他系统明确阻断，不自动退回无隔离执行，不下载 SDK 或游戏依赖。

```sh
# 三种结构和一次修改：真实编译及序列对照，无云端请求
npm run verify:execution

# 一次自有 C# 语法错误：确认诊断保存与下游阻断
npm run verify:diagnostics

# 编译明确指定的规格 JSON；可用第二个参数指定本地 SDK 根目录
npm run behavior:compile -- /absolute/path/input.json
```

每次创建独立私有目录，失败记录不被下一次覆盖。输入必须包含：

| 字段 | 含义 |
| --- | --- |
| `schemaVersion` | 固定为 1 |
| `request` | 宿主、来源、原始描述和内容类型 |
| `requirementIds` | 从原始需求独立绑定的 ID 清单 |
| `spec` | BehaviorSpec v1 |
| `steps` | 输入序列，可含 `expected` 状态与 `error` 接受/拒绝断言 |

输入为有界普通 UTF-8 JSON，拒绝链接、已知凭据及凭据字段、未知入口字段和 getter。API 为 `createBehaviorExecutionRuntime()`；没有新增 HTTP 命令或文件写入接口。

## 行为规格与语义

`src/behavior/` 导出 `validateBehaviorSpec`、`createBehaviorMachine`、`emitCSharpBehavior`。规格包含需求 ID、初始状态、状态集合、整数变量及范围、事件输入字段，以及带优先级、守卫、需求引用、目标状态和同时更新的转换。无法表达的需求保留在 `unresolved` 并阻断完整执行验收。

表达式仅允许整数/布尔字面量、已定义变量和事件字段、加减、最值、比较与布尔操作。中间值限制在 ±10⁹。优先级较小者先匹配；同一状态/事件内不允许优先级冲突。无匹配时保留状态，输入或更新出错时整步拒绝，不部分提交。

JSON 无法保真传递 JavaScript 负零，所以向量明确拒绝 `-0`。只有全部步骤带明确预期时才报告 `matchesDeclaredVectors=true`；只有 JS/C# 一致时该字段为 false。ID 覆盖不证明自然语言理解完整，也不证明来源保真。

## 文件、工具与编译边界

`src/artifacts/store.mjs` 以不含绝对路径的 handle 传递工程和二进制，快照保存 handle 和结果元数据。清单含逐文件 SHA-256、大小、类型与来源；源文件、程序集和验证输入在执行前后核对哈希。路径仅接受有界 ASCII 相对名，拒绝父目录、绝对路径、反斜线、大小写冲突、保留名、链接和特殊文件。默认每份最多 64 文件，单文件 2 MiB，总计 8 MiB。目录 0700、保存文件 0600；这是文件管理边界，不能替代 OS 隔离。

工程文件、依赖、参数与验证程序由本地锁定，规格仅决定纯行为类。NuGet 源清空，关闭共享编译、分析器、Git 和 SourceLink 信息收集。恢复绑定 SDK 版本、目标框架及 dotnet/C# 编译器哈希；这些指纹不是整个 SDK 的签名或供应链证明。

子进程不继承 Key、Git 凭据或启动钩子，只写本次工作区。凭据读取和网络被 OS 策略拒绝，策略在可写区之外，执行前先做正反控制。调用者只能传超时和取消选项，不能覆盖环境或目录。超时按进程组终止并截止返回，不能保证杀死已脱离的全部后代。当前只运行自有生成器与验证程序，不执行任意模型源码。

失败保留安全错误码；实际编译输出作为 `failureArtifact` 单独保存，不直接传播原始异常消息。没有自动模型修复或收费重试。

新增 `kind=tool`，按精确 `toolchains` 和 `formats` 匹配，无需按每款游戏重复登记。工具只使用 `tool.*` 能力与产物，不能登记游戏兼容或输出 Mod/游戏证据。游戏适配器仍要求精确游戏、版本、平台和接口依据。新分析运行保存本机平台，新生成节点直接接收五份上游；旧图仍可读取恢复，不补造历史环境。

## 本轮证据与未完成项

2026-11-04：完整 `npm test` 为 **156/156、0 跳过**，构建通过；OS 沙盒通用底座 **49/49、0 跳过**。独立真实编译验收的四份源码和四个 DLL 哈希各不相同，重启读取与完成任务去重通过。沙盒底座测试、行为序列和实际编译分别计数，不合并为游戏成功率。

实际 SDK 编译了时序互斥、资源预留/回滚、序列窗口/取消三种结构，并将第一种修改为暂停/恢复；40 步与预期及 JS 一致，含 7 次预期拒绝。外部 JSON 文件入口也完成编译验证。用例属于执行内核测试，不是游戏玩法产物，也不覆盖所有算子和状态路径。

另一次真实受控故障返回 `CS1525`：编译任务 `failed`，下游 `blocked`，诊断可按 handle 读回，零重试、零 DLL 执行。最初 SDK 收集 Git 信息触发沙盒拒读的失败记录保留，随后关闭该无关功能。本轮云端模型调用为零。

当前仍缺：自然语言到规格的自动桥接、来源资料与资源工具、宿主行为绑定、Mod 工程后端、真实 Mod 编译/修复和游戏验收。当前证据仅证明执行内核可处理不同输入并真实编译。

接口出处：[.NET build](https://learn.microsoft.com/en-us/dotnet/core/tools/dotnet-build)、[CLI 遥测开关](https://learn.microsoft.com/en-us/dotnet/core/tools/telemetry)、[Node.js 24 文件接口](https://nodejs.org/docs/latest-v24.x/api/fs.html)。BehaviorSpec 为项目自有 v1 合同。
