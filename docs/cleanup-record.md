# 转换器方向清理记录

日期：2026-11-02（Asia/Shanghai），版本 0.6.0 Alpha。

产品主线恢复为跨游戏 AI 内容与玩法转换器：保留完整需求，分析来源、资源与宿主接口，编排转换任务，逐步生成工程、构建和验收。此前单游戏固定模板与探针没有实现这一通用目标，退出当前产品入口和执行流程。

## 本轮清理范围

- 移除固定 SMAPI Buff 制作入口、Xonotic 枪械生成链路、tModLoader 专用探针，以及对应页面、任务接口、脚本和演示产物。
- 移除将场景转换、独立小游戏、固定动作回放或单宿主模板作为产品成果的旧说明。
- 保留并重新组织可复用的模型连接、凭据 origin 绑定、取消、结构校验、需求保留与阶段证据边界。
- 项目自有下载、测试副本和生成包移出工作区与站点，使用可恢复方式清理。用户凭据、游戏文件、地图与存档不在删除范围内；通用开发工具按其用途保留。

Git 使用普通提交记录本轮变更，不重写历史。旧提交中的实验结果不构成当前支持范围，当前页面与文档不再以这些原型作为交付成果。

## 历史证据保留的结论

此前曾真实调用模型完成部分计划或源码生成，并进行受控语法故障修复；也出现过模型格式或语义校验失败。旧规则回放、契约模拟器和语法解析只验证各自范围，不能算作 Mod 编译或游戏成功。

Xonotic 支线曾针对官方固定源码与本地 QuakeC 工具完成有限规则的真实编译，也曾初始化图形客户端、渲染原版地图并加载 Bot。部分真实模型返回未通过计划校验，后续修正提示后产生了可编译计划。完整 AI 产物的射击、换弹和真实命中验收没有完成；这些结果不证明转换器已通用，也不构成已验收游戏组合。

清理不将失败改写成成功。当前适配器注册表为空，工程生成、构建修复与游戏执行均未接入新的通用转换流程；当前可交付的是需求分析与任务规划底座。

## 本轮验证

- 78 项明确识别的旧路径（含目录）已移至本机废纸篓，覆盖旧代码、实验包、游戏副本、截图及日志；工作区和构建目录不再提供这些入口与产物。通用 SDK、GitHub CLI、认证和本地 `.env` 保留。
- `npm test`：46 项通过，0 失败、0 跳过。测试覆盖通用合同、模型传输、凭据隔离、取消、任务图、HTTP/界面边界和通用基础设施；不构成真实模型调用或游戏转换实测。
- `npm run build`：通过；输出仅包含转换器首页、两份前端资源与三份当前文档。旧页面与专用执行接口已移除。
- 浏览器已确认本地转换器入口、未预填游戏和独立状态说明；布局未发生横向溢出。
- 清理过程没有发起收费模型调用，没有启动游戏，没有修改用户凭据或重写 Git 历史。
