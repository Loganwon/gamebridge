# GameBridge 动作制作验收记录

日期：2026-10-30（Asia/Shanghai）。版本：0.5.0 Alpha。

本轮打通需求到动作规则、宿主能力门控、确定性回放和设计导出。**没有完成真实动作 Mod 生成、真实 Mod 编译或游戏内运行。** `realModBuild=not_run`、`game=not_run`、`readyToInstall=false`。

## 新增实现

新增声明式动作蓝图、受限规则解释器和本地决定的宿主检查。首页转为动作工作台，旧 SMAPI Buff 工程与构建修复保留在 `/pipeline.html`。公开页面可回放项目自有示例；模型设置与调用仅限本地服务。

蓝图可以表达攻击阶段、命中条件连段、取消窗口、体力与受击中断。闪避只表示状态，没有真实位移、无敌帧、动画、碰撞或伤害。无法表达的需求保留为空规则和缺口，不转成示例。规则与场景数量、时间、字节和轨迹都有本地上限。

## 发现的问题和修正

旧分析接口改为提示和校验共享机器可读结构规范，提供完整示例，并将 JSON、结构和语义错误分类。资源数组仍严格要求字符串，不做对象强制转字符串，也不自动收费重试。此前的模型格式失败继续保留在 [历史沙盒报告](sandbox-verification.md)。本轮只有一次旧接口新分析抽检通过，不能宣布稳定性问题已解决。

新动作分析的第一份模型结果把“本次不生成 Mod”这一范围说明误分类为 `unsupported` 的必需需求。该项未被删掉或算为已满足。提示现已要求将此类范围约束放入 limitations；预算结束后没有追加付费调用，因此这一提示修正尚未经过新的真实抽检。完整需求理解与分类仍需评估。

只读对抗审查还发现：忽略取消的生成器可能晚返回，而接口继续保存结果。现已在返回和发布前检查取消状态，并以晚返回回归测试验证丢弃结果及后续请求正常运行。界面连接检查也修正为配置完整后才启用 AI。

测试覆盖畸形蓝图与场景、资源和时长边界、未知宿主、版本缺口、伪造本地验收字段、凭据回显、跨域、导出与取消。稀疏巨型数组与过深结构在 JSON 序列化前拒绝，避免校验本身扩大输入。模拟通过不会解锁真实游戏状态。

本地 `npm test` 共 141 项通过、0 跳过，`npm run build` 通过。实际浏览器检查了三种规则差异、中文回放结果和设计下载；下载 JSON 含 8 个自有场景记录，不含凭据，来源标为项目示例，真实构建和游戏状态仍为未运行。未在浏览器额外调用收费模型。

GitHub 检查新增无模型调用的 `npm run verify:actions`，公开发布前回放固定规则；云端流水线不保存 Key、不调用收费模型。
