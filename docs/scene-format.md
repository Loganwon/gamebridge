# GameBridge Scene v1

```json
{
  "version": 1,
  "name": "two-block-marker",
  "size": [2, 1, 1],
  "palette": ["#aabbcc", "#ff9900"],
  "voxels": [
    {"x": 0, "y": 0, "z": 0, "color": 0},
    {"x": 1, "y": 0, "z": 0, "color": 1}
  ]
}
```

场景使用 Y 向上的右手坐标系。`size` 是含空格的格点尺寸，三个整数均为 1–128。体素坐标代表方块最小角，必须位于尺寸内且不重复。`color` 为 `palette` 从 0 开始的索引。调色板支持 1–256 个六位 RGB 颜色。空格不记录，透明度和渲染材质不在 v1 协议内。

场景名称 1–80 字符，不允许换行或控制字符。`version` 必须精确为数字 1。体素数为 1–32,768；字段均经类型和边界验证，不执行源文件中的表达式。适配器不得把原文件的代码或元数据当作命令执行。

MagicaVoxel `(x,y,z)` 转换为 `(x,z,sizeY-1-y)`，保留朝向的手性；变换后的尺寸为 `[sizeX,sizeZ,sizeY]`。Minecraft 建筑使用它原来的 Y 向上轴序。所有来源使用非负局部坐标；存档的绝对世界原点不沿用。

`transformScene` 支持绕 Y 轴旋转 0/90/180/270 度、X 方向镜像和 1–4 倍整数缩放。旋转在原点归一化后保持非负坐标；缩放复制整个格子体积。必须在分配输出前检查尺寸和体素数量。

新增来源适配器应返回上述结构，再调用 `validateScene`；新增导出器应在 `TARGETS` 中注册并返回 `{ filename, text, mime, report }`。转换报告描述体素数、目标尺寸、材质近似和特征损失。网页预览显示统一场景颜色，Minecraft 的有限方块调色板会产生差异。

版本升级采用显式 `version`，不默默改变旧格式字段。真实目标软件的导入验收需要单独记录版本和结果。
