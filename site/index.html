    这是可运行的场景转换原型。首版转换体素几何与颜色，不包含角色、脚本、纹理或游戏玩法。导出格式已实现，目标游戏和编辑器的实机导入尚未验收。

    01 / 支持什么文件？

    导入 Minecraft WorldEdit / Sponge v2、v3 建筑 .schem、单模型 MagicaVoxel .vox，或 GameBridge .json。不支持完整世界存档（.mcworld / .mca）或直接提取其他游戏地图。Minecraft 建筑仅保留静态形状和近似颜色，不保留实体、红石逻辑和方块实体数据。可先加载示例，再导出 JSON 查看格式。

    02 / 怎样导入目标游戏？

    Minecraft Java 1.21
    将 .mcfunction 放入符合当前版本要求的数据包 data/<命名空间>/function/ 中。在自己的测试世界加载数据包，并通过 /function 命名空间:文件名 执行。函数以执行位置为原点放置方块，可能覆盖已有建筑；请使用空白测试区域。不是直接粘贴到聊天框的命令清单。
    Roblox Studio
    在自己项目的 Studio 编辑模式中，将 .lua 内容粘贴到 Command Bar 执行，生成独立模型。只在 Studio 使用，不在运行中的在线游戏执行。
    Godot 4
    将 .tscn 放入项目资源目录并打开场景。输出为静态可视方块，不包含碰撞体、物理或游戏逻辑。
    GameBridge JSON
    保存可重复编辑的中间场景格式，或作为后续游戏适配器的输入。

    03 / 关于游戏规则与反作弊

    GameBridge 不连接游戏进程；通过本地文件和创作工具完成转换。每款游戏的导入能力和使用规则不同，无法承诺任何模式下都不触发反作弊。请在你有权编辑的离线世界、私人测试世界或官方编辑器中使用。

    所有转换都在当前浏览器完成，导入的场景文件不会上传。
